## 🔀 Workflows Clés

### Workflow 1: Setup Nouveau Monorepo
```
1. Lire SETUP-GUIDE.md complètement (30 min)
2. Copier templates de packages-templates.md
3. Adapter à votre structure
4. Suivre checklist phase par phase
5. Valider avec SKILL checklist
→ Result: Monorepo opérationnel
```

### Workflow 2: Ajouter Dépendance
```
1. Consulter skills/packages/SKILL.md
2. Suivre la checklist
3. Exécuter les commandes
4. Si blocage: consulter SETUP-GUIDE.md
→ Result: Dépendance ajoutée correctement
```

### Workflow 3: Décision Architecturale
```
1. Lire packages.md (comprendre options)
2. Consulter agent decision framework
3. Valider avec SETUP-GUIDE.md patterns
4. Implémenter
→ Result: Décision bien fondée
```
