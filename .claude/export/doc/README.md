# Documentation (Base Générique)

Ce dossier contient des éléments de documentation réutilisables pour Generic Project et autres monorepos.

## Fichiers Inclus

### 📦 Gestion des Packages
- **packages.md**: Guide complet de gestion des packages, npm workspaces, versions et dépendances
- **packages-templates.md**: Templates complets de `package.json` pour tous les types d'apps (backend, frontend, mobile, packages internes)
- **SETUP-GUIDE.md**: Guide pratique d'implémentation pas-à-pas pour intégrer package management dans votre projet
- **PACKAGE-MANAGEMENT-CONTENT.md**: Vue d'ensemble du contenu packages (carte mentale, couverture, flux)
- **SUMMARY.md**: Résumé des ajouts et statistiques
- **Associated Skills**: `skills/packages/SKILL.md` - Skill dédié au Package Management
- **Associated Agent**: `agents/dependency-manager.md` - Agent expert en gestion des dépendances

## 📚 Comment Naviguer

### Pour Démarrer (Nouveau Projet)
1. Lire [SUMMARY.md](./SUMMARY.md) - Vue d'ensemble (5 min)
2. Lire [SETUP-GUIDE.md](./SETUP-GUIDE.md) - Implémentation (20 min)
3. Copier templates de [packages-templates.md](./packages-templates.md)

### Pour Comprendre les Concepts
1. Lire [packages.md](./packages.md) - Guide complet (30 min)
2. Consulter [PACKAGE-MANAGEMENT-CONTENT.md](./PACKAGE-MANAGEMENT-CONTENT.md) - Couverture (10 min)

### Pour Opérations Courantes
- Voir [skills/packages/SKILL.md](../skills/packages/SKILL.md) - Checklist
- Consulter [SETUP-GUIDE.md](./SETUP-GUIDE.md) - Troubleshooting

### Pour Décisions Complexes
- Utiliser [agents/dependency-manager.md](../agents/dependency-manager.md) - Framework expert
