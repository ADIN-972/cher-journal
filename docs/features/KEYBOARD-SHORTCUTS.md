# Keyboard Shortcuts

## Admin Interface

### Navigation
| Shortcut | Action |
|----------|--------|
| `Ctrl+/` | Focus search bar |
| `Esc` | Close modal/dialog |
| `Alt+D` | Go to Dashboard |
| `Alt+C` | Go to Chapters |
| `Alt+U` | Go to Users |
| `Alt+O` | Go to Orders |

### Actions
| Shortcut | Action |
|----------|--------|
| `Ctrl+N` | New Chapter |
| `Ctrl+E` | Edit selected item |
| `Ctrl+S` | Save form |
| `Delete` | Delete selected item (with confirmation) |

### Forms
| Shortcut | Action |
|----------|--------|
| `Tab` | Next field |
| `Shift+Tab` | Previous field |
| `Enter` | Submit form |
| `Esc` | Cancel/Close |

### Tables
| Shortcut | Action |
|----------|--------|
| `↑` | Previous row |
| `↓` | Next row |
| `PageUp` | Previous page |
| `PageDown` | Next page |

## Reader Interface (Web/Mobile)

### Navigation
| Shortcut | Action |
|----------|--------|
| `←` or `A` | Previous page |
| `→` or `D` | Next page |
| `Home` | First page |
| `End` | Last page |
| `Space` | Next page |
| `Shift+Space` | Previous page |

### View Controls
| Shortcut | Action |
|----------|--------|
| `F` | Toggle fullscreen |
| `+` | Zoom in |
| `-` | Zoom out |
| `0` | Reset zoom |
| `M` | Toggle menu |

### Settings
| Shortcut | Action |
|----------|--------|
| `T` | Toggle theme (light/dark) |
| `P` | Switch perspective (narrator/protagonist) |
| `S` | Open settings |

## Development

### VS Code (with Copilot)
| Shortcut | Action |
|----------|--------|
| `Ctrl+Shift+P` | Command palette |
| `Ctrl+P` | Quick file open |
| `Ctrl+Shift+F` | Search in files |
| `Ctrl+`` ` | Toggle terminal |
| `F5` | Start debugging |

### Browser DevTools
| Shortcut | Action |
|----------|--------|
| `F12` | Open DevTools |
| `Ctrl+Shift+C` | Inspect element |
| `Ctrl+Shift+M` | Toggle device toolbar |
| `Ctrl+R` | Reload page |
| `Ctrl+Shift+R` | Hard reload (clear cache) |

## Notes

- Shortcuts may vary by operating system (Windows/Mac/Linux)
- On Mac, replace `Ctrl` with `Cmd`
- Custom shortcuts can be configured in user settings
- Some shortcuts may conflict with browser/OS defaults
